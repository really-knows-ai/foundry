- [x] `docs/tools.md` describes the old commit-message-based attestation tool interface, not the implemented JSONL-based interface — the documented args, return formats, and failure modes describe the old system and do not match the current implementation
- [x] Quench attestation records store only a violation count, not the violations found — `buildQuenchAttestationParams` sets `violations` to `feedbackList.length` (a number) and the stage-payload schema defines `violations` as `number`, but the spec states "Each quench record lists violations found"
- [x] `foundry_attestation_verify` does not cross-check the cycle line's `_hash` against the git commit message — it only verifies internal consistency of the JSONL file, but the spec states an auditor can verify the cycle line's `_hash` against the commit message to confirm the commit hasn't been tampered with
- [x] In `src/scripts/lib/attestation/hash.js`, `handleMismatchLine` throws an error for cycle attestation lines with a hash mismatch — the spec says the seal function "skips lines whose `_hash` does not verify" (cycle lines should be skipped like any other line, not throw)
- [x] In `src/scripts/lib/attestation/cycle-payload.js`, `buildCycleAttestation` throws a `TypeError` when `stage_attestations` is an empty array — the spec says `buildCycleAttestation` should be used for all verified stage attestations, but the implementation works around this with a local `buildMinimalCycle` helper
- [x] Hash mismatch on a stage line — the mismatched attestation is excluded from the composite entirely (the `continue` statement skips it) rather than being included with the `_hash_mismatch` flag preserved as the spec describes
- [x] "Six stage-execution paths" count mismatch — `VALID_STAGES` in `stage-payload.js` defines only 5 stages (`assay`, `forge`, `quench`, `appraise`, `human-appraise`) and only 5 append functions exist in `executor-attestation.js`, but the spec requires six stage-execution paths
- [x] Verification commands using `--test-path-pattern` use a Jest flag not supported by the Node.js built-in test runner used by this project
- [ ] The `pnpm test` script uses `find` which excludes `.e2e.test.js` files, so `pnpm test -- tests/plugin/git-tools.e2e.test.js` would not execute that file
